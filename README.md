# Wayfarer

A self-contained, top-down 2D adventure game about exploring a procedurally generated world, fighting monsters, finding treasure, and earning a name as an adventurer.

## Play

Open [index.html](index.html) in a modern desktop browser. The game runs locally and stores saves in browser local storage.

## Current playtest

Build 0.183.0 is the latest packaged playtest. It includes graphical shop stock cards, shopkeepers in every active shop, walk-through NPC movement, and companion interaction prompts that stay out of the way unless a personal story is ready.

[Download the packaged game](release/Wayfarer-Playtest-0.183.0.zip)

## Controls

- **WASD / arrow keys** to move. Each move or action advances one game tick.
- **E** to interact with nearby people and objects.
- **Double-click** a nearby person to talk, or another tile to inspect it.
- **M** to open the discovered world map.
- **Shift+A** to choose an attack or spell.
- **B** to enter camp and fortress building mode.
- **J** to open the travel journal.

See the in-game help panel for the full control list.
